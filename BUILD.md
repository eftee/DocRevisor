# DocRevisor

Derivative build of [storytold/pdfcraft](https://github.com/storytold/pdfcraft), pinned to v0.19.0. Original MIT/Apache-2.0 license notices and author attribution must remain available.

Windows builds are performed with GitHub Actions and require no toolchain on the user's computer. The build is unsigned; it does not override company-managed device policies. Test the resulting executable on an authorized Windows system before use.
